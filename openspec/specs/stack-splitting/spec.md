# stack-splitting Specification

## Purpose
定义部分数量移动（半组/单件）与快捷搬运在三个视图域（背包、合成、容器）内的权威原子语义、服务端数量推导与固定确定性目标序，以及两条 pure-append 命令的协议值域。
## Requirements
### Requirement: 半组与单件移动是权威原子操作

系统 SHALL 提供部分数量移动命令：在背包（0..35）、合成视图（网格 0..8 + 背包 9..44）与容器视图（箱子 0..62、熔炉 0..38 统一索引）三个视图域内，把来源格的恰好一半（向上取整）或恰好 1 个物品移动到目标格。移动数量 MUST 由服务端按来源栈推导（半组 `ceil(n/2)`、单件 1），客户端 MUST NOT 能请求任意数量。部分移动 MUST 在局部副本上试算成功后原子写回；目标为非同类非空格时 MUST 稳定拒绝且不修改任何栏位（部分移动不做交换）。合成域 MUST 复用既有网格边界与背包重打包不变量预演；容器域 MUST 复用既有熔炉槽位物品约束（输入、燃料、输出只可为源）与箱子视图规则。拒绝 MUST 复用既有拒绝原因枚举。

#### Scenario: 半组移动数量由服务端推导

- **GIVEN** 来源格有 7 个同类物品、目标格为空
- **WHEN** 玩家提交半组移动请求
- **THEN** 恰好 4 个物品移入目标格、3 个留在来源格，两侧数量一致于请求时点

#### Scenario: 单件移动进同类未满格

- **GIVEN** 目标格已有同类物品 63 个（上限 64）
- **WHEN** 玩家提交单件移动请求
- **THEN** 恰好 1 个物品并入目标格，来源减 1

#### Scenario: 异类非空目标整单拒绝

- **GIVEN** 目标格装有与来源不同的物品
- **WHEN** 玩家提交半组或单件移动请求
- **THEN** 请求 MUST 被稳定拒绝，任何栏位 MUST NOT 变化

#### Scenario: 合成域部分移动保持重打包不变量

- **GIVEN** 个人 2×2 网格处于合法占用状态且背包仅剩 1 个空格
- **WHEN** 一笔会把网格占用加重到无法整体装回背包的半组移动提交
- **THEN** 该移动 MUST 整体拒绝且逐格不变

#### Scenario: 熔炉槽位约束沿既有规则

- **GIVEN** 熔炉视图内目标为燃料槽且来源物品不是煤
- **WHEN** 玩家提交单件移动请求
- **THEN** 请求 MUST 被拒绝；输入槽仅接受熔炼表内物品、输出槽只可作为来源的既有规则逐条保持

### Requirement: 快捷搬运按固定目标序整堆转移

系统 SHALL 提供快捷搬运命令：把来源格整堆移动到对侧区域首个可容纳位置，目标序为固定确定性契约。容器视图内：容器区来源 MUST 按既有拾取四相位序并入玩家背包；背包来源在箱子视图 MUST 按统一索引 36..62 升序进首个空或同类未满格，在熔炉视图 MUST 按「熔炼输入优先于燃料」的槽位优先级（物品两类皆可时入输入槽）落位。合成视图内：网格来源 MUST 并入背包；背包来源 MUST 按网格 0..8 升序进首个空或同类未满格并保持重打包不变量。纯背包面板内：快捷栏与背包区 MUST 互移到对侧区域。任何方向无可容纳位置或容量不足时 MUST 稳定拒绝且不修改任何栏位；部分可容纳时按既有合并语义执行（余量留源）。

#### Scenario: 箱子整堆快捷搬运回背包

- **GIVEN** 箱子某格有 64 个石头且背包有空位
- **WHEN** 玩家提交该格的快捷搬运请求
- **THEN** 整堆按拾取四相位序并入背包，箱子该格清空

#### Scenario: 背包快捷搬运进熔炉的槽位优先级

- **GIVEN** 背包格装有生铁（熔炼输入）且熔炉输入与燃料槽均可容纳
- **WHEN** 玩家提交该格快捷搬运
- **THEN** 整堆进入输入槽；同一物品若同时是燃料与输入，输入槽优先

#### Scenario: 无可容纳位置整单拒绝

- **GIVEN** 箱子 27 格全部为异类非空
- **WHEN** 玩家提交背包某格的快捷搬运
- **THEN** 请求 MUST 被稳定拒绝且不修改任何栏位

#### Scenario: 目标序确定可重放

- **GIVEN** 相同的栏位布局与请求序列
- **WHEN** 两次独立运行处理相同快捷搬运序列
- **THEN** 每一步的落位与余量 MUST 逐格一致

### Requirement: 分堆命令以 pure-append 进入协议

两条新客户端命令 SHALL 以 pure-append 方式加入协议（不重排、不改义任何既有消息）：部分移动命令携带视图域、来源/目标统一索引与单件标志；快捷搬运命令携带视图域与来源统一索引。视图域枚举 MUST 为 {背包, 合成, 容器}；容器视图命令 MUST 携带合法容器引用，非容器视图命令的容器引用字段 MUST 为零值。索引越界、视图域非法、容器引用非法、来源等于目标（部分移动）MUST 在协议校验层整包拒绝。

#### Scenario: 非法视图与零值引用约束

- **GIVEN** 一条视图域为 2 但容器引用为零值的部分移动命令
- **WHEN** 协议校验
- **THEN** 命令 MUST 被拒绝；视图域为 0 却携带非零容器引用同样拒绝

#### Scenario: 域内索引上界按视图分派

- **GIVEN** 合成视图命令的目标索引为 45，或箱子视图命令的来源索引为 63
- **WHEN** 协议校验
- **THEN** 命令 MUST 被拒绝
