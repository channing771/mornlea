## MODIFIED Requirements

### Requirement: 缺失玩家材料包

> 标题为匹配主规格的 MODIFIED 漂移守卫而保留；本变更后不再存在任何一次性材料包，缺失玩家的初始背包恒为空。

系统 SHALL 只在玩家存档明确不存在时构造一次新玩家初始背包，且该背包 MUST 完全为空：九格快捷栏与 27 格背包的全部栏位 MUST 为空槽，系统 MUST NOT 依任何材料清单填入物品或工具。空初始背包 MUST 通过现有背包合法性规则，并仍由服务端权威确认与持久化。已有玩家的全部快捷栏与背包栏位（包括历史材料包留下的十四组整栈材料与起步种子）MUST 逐槽保留，MUST NOT 删除、补发、重排或清零。

#### Scenario: 缺失玩家获得固定材料包

> 标题为匹配主规格的 MODIFIED 漂移守卫而保留；本变更后的断言明确取消材料包。

- **GIVEN** `LoadPlayer` 返回 `ErrPlayerNotFound`
- **WHEN** 准备玩家快照
- **THEN** 快捷栏九格与背包 27 格 MUST 全部为空槽
- **AND** 系统 MUST NOT 填入材料、种子、工具或任何其它物品

#### Scenario: 已有玩家与未确认登录不被补发

- **GIVEN** 已有玩家或未确认登录
- **WHEN** 恢复、迁移或断开
- **THEN** 已有快捷栏与背包全部栏位 MUST 逐槽不变且未确认的初始背包 MUST 不持久化或累加
- **AND** 已有栏位中的历史材料 MUST 不被删除、补发、重排或清零

#### Scenario: 确认后的新玩家不会重复获得材料

- **GIVEN** 新玩家已确认登录并保存包含空初始背包的快照
- **WHEN** 该玩家再次登录
- **THEN** 系统 MUST 恢复已保存背包，且 MUST NOT 在任何时刻填充或累加材料

#### Scenario: 材料包含有起步种子

> 标题为匹配主规格的 MODIFIED 漂移守卫而保留；本变更后的断言为空初始背包不含任何物品，起步种子的禁令随之空洞化成立。

- **GIVEN** `LoadPlayer` 返回 `ErrPlayerNotFound`
- **WHEN** 准备玩家快照
- **THEN** 背包与快捷栏 MUST 不包含任何小麦种子
- **AND** MUST NOT 以其它初始栏位替代任何被取消的发放

### Requirement: 新世界起点保证关键能力可达

新玩家在缺省世界生成下以空初始背包起步时，服务端 SHALL 保证工作台、照明、采掘工具与食物四条关键能力各自存在一条只经自然获取与既有采掘、合成、熔炼规则即可走通的路径。以自然获取集合为起点、按既有规则求值到不动点的价值闭包中，四条能力所需的物品 MUST 全部位于闭包内；并且 MUST NOT 存在任何配方或熔炼以「无自然来源且不在闭包内」的物品作为必需输入。取消一次性发放 MUST NOT 把任何既有已交付内容（含熔炉、熔炼产物、铁锭与空桶）推出闭包。

#### Scenario: 价值闭包覆盖四条关键能力

- **GIVEN** 自然获取集合（徒手或任意手持可采收的方块掉落、自然生成的作物与被动生物掉落、环境移除掉落）与固定配方表、熔炼表
- **WHEN** 从该集合出发对采掘、合成、熔炼规则求价值闭包的不动点
- **THEN** 工作台、火把、至少一种镐、面包或熟肉 MUST 位于闭包内
- **AND** 熔炉、铁锭与空桶 MUST 位于闭包内
- **AND** 不在闭包内的物品集合 MUST 恰为不自然生成的装饰材料

#### Scenario: 徒手起家路径不依赖任何一次性发放

- **GIVEN** 新生成的缺省世界与空初始背包
- **WHEN** 玩家只使用徒手采掘世界方块并按下述顺序推进：采掘橡木原木、合成橡木木板、合成并放置工作台、合成石镐
- **THEN** 每一步 MUST 成功，且 MUST NOT 依赖任何初始发放或测试直给物品

#### Scenario: 装饰材料不阻塞关键能力

- **GIVEN** 圆石、平滑石、苔藓圆石、白色羊毛与红色瓦块等不自然生成的装饰材料
- **WHEN** 检查四条关键能力路径上的全部配方与熔炼
- **THEN** 这些材料 MUST NOT 作为必需输入出现
