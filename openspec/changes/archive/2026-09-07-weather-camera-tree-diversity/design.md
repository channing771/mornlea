## Context

现状见 proposal Why；约束：服务端唯一权威、Memory 与 TCP 复用同一登录/模拟/校验路径；Go 只经既有 ABI bridge 调 Rust、无生产 fallback；任何 Go 包不得导入 WebGPU；权威 tick/渲染/网络热路径不得无界工作或阻塞 I/O；跨 goroutine 发送成功后的消息及切片视为不可变。当前昼夜（`WorldTimeTicks`+`DayPhaseOffset`、metadata v3、协议 v35）与天空（程序化渐变/日月/星空/方块云）已落地；相机为第一人称眼睛直连 `Camera::ViewProj`；橡树为 Go 只编解码、Rust `mornlea_engine/worldgen.rs` 独占生产的 8×8 候选格固定四层冠（树高 4-6）。

## Goals / Non-Goals

**Goals:**
- 天气权威时钟与同步持久化做到常数工作量、多人一致、可重放；雨雪形态为纯本地派生，不进权威。
- 视角三态做到纯本地、跨世界保留、防穿墙，瞄准语义不变。
- 树多样性做到种子确定、单点=整块、跨块无缝、老块不变，Go/Rust parity。

**Non-Goals:**
- 不做群系系统、不联动玩法数值（钓鱼/作物/刷怪/睡眠）、不做闪电伤害。
- 不做电影运镜、不做服务端同步视角。
- 不引入新树种/新方块、不改地形噪声与矿石。

## Decisions

### D1 天气状态机放在服务端 sim tick 内（而非独立 goroutine/客户端自治）

- 做法：`WeatherKind u8 + Remaining u32` 随权威 tick 递减，到期掷骰（确定性 RNG，经种子派生、与地形噪声隔离）；`PlayerState` 尾部追加 1 字节（v36），metadata v4 持久化。
- 理由：复用既有 tick 门与 `ServerTick` 去重，Memory/TCP 自动一致；常数工作量、无 I/O。
- 否决：客户端本地随机（多人不一致，违权威边界）；独立天气线程（并发与重放复杂）。

### D2 天气表现复用昼夜管线（而非新光照模型）

- 做法：雨/雷暴只压暗 `daylight` 上限并灰化天空 uniform，降水粒子为相机前有界 quad 流（雨线与雪点复用同一通道，按高度相对既有雪线选形）；雷暴加固定上限闪光；不触发重网格，不新增 GPU 资源类型。
- 理由：`authoritative-daylight` 与 `celestial-sky-presentation` 已有固定成本与覆盖顺序契约，改动最小。
- 否决：重做天空光传播（需改 `light.rs` BFS 与阻断判据，风险大）。

### D3 视角为纯客户端本地模式（而非服务端同步）

- 做法：`CameraMode` 存本地设置；第三人称相机=眼睛±前向×距离，经体素射线对完整不透明方块 pull-in；自身模型显隐与 viewmodel 显隐互斥。
- 理由：视角不影响权威模拟，本地化避免协议 churn；瞄准仍用眼睛射线保证手感一致。
- 否决：服务端同步视角（多 1 字节 wire 与一致性负担，无玩法收益）。

### D4 树多样性只扩展哈希位消费（而非新噪声/新表）

- 做法：沿用 `OAK_TREE_SALT` 哈希，将高位未用比特分配给高度 5-7、冠形两档、珍异 8% 判定与分杈方向；Go 侧不加生产逻辑，仅 parity/golden 更新。
- 理由：单 cell 常数工作量不变，单点/整块/跨块一致性证明沿用现有遍历半径（分杈半径需复核上界，见风险）。
- 否决：引入新树种表或群系相关规则（需新材料与群系系统，超范围）。

## Risks / Trade-offs

- [合一 change 回退粒度粗] → 按 tasks 分 A/B/C 三组，每组独立失败测试与验证命令，可按组 revert。
- [协议 v36/ metadata v4 老客户端/老档] → 越界拒绝+版本门，v3→v4 迁移默认晴天，不扫描老区块。
- [珍异分杈扩大覆盖半径导致跨块查询漏树] → 以分杈最大伸展重算 cell 邻域半径并加跨界单测钉住。
- [第三人称穿墙/抖动] → pull-in 取最近阻挡减 epsilon，完全遮挡收至眼睛；相机不写权威。
- [雨粒子热路径分配] → 复用调用方缓冲、固定上限实例数，稳定帧零分配由单测断言。
- [雪线判定多人一致] → 雪线阈值复用既有地表材料雪线常量，纯本地只读计算，不进权威不同步。

## Migration Plan

- 部署：协议 v36 与 metadata v4 同批上线；旧服务端拒绝新字段，旧客户端拒绝 v36（显式错误，不静默截断）。
- 数据：v3 世界首次打开迁移为晴天；已保存区块不重写，只有新生成区块呈现新树。
- 回退：整分支 revert；若只回退一组，需同步 revert 其 spec delta 与 golden（tasks 标注对应文件）。
