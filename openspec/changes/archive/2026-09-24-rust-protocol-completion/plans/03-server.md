# Server packet worker packets

Each node consumes [the boundary/evidence contract](01-boundaries.md#shared-packet-case-contract), [design.md](../design.md) and [wire-matrix.md](../wire-matrix.md). For each listed `protocol.server.<Name>` family, commit a valid Go-produced decode case, a valid Go-produced encode case and the named negative/boundary cases at version 45 with its exact S/state/ID key. The Go producer calls actual `codec.Codec.EncodeServer/DecodeServer` and `protocol.ValidateServerPacket`; Rust executes its real packet method and compares every field. Fixed payloads <=256 bytes test all proper truncations and one trailing byte. Variable payloads test cuts at 0, 1, every header boundary, first/last record boundary and length−1, then a trailing byte; a count above the ceiling must fail before record allocation. Mutable public structs must be revalidated before caller-buffer writes, with invalid-value precedence and an untouched `0xa5` destination. The controller owns serial manifest/`lib.rs`/route integration. A packet group's scoped commit and rollback include only its named modules, producer, consumer and reviewed corpus assets; no online server or Go production change belongs here.

## 3.2 — Compact chunk snapshot and zstd context

**Predecessors:** 1.2, 1.3, 3.1. **Deliverable:** one S/Play/0 snapshot can be decoded by either implementation and encoded through a bounded owned context. **Editable:** `PROTOCOL/src/chunk_snapshot.rs`, new `PROTOCOL/src/codec.rs`, `PROTOCOL/src/lib.rs`, new `PROTOCOL/tests/protocol_snapshot.rs`, new `ORACLE/protocol_snapshot_test.go`, `CORPUS/cases/protocol/ChunkSnapshot/`, its routes in `ORACLE/inventory.go`, `PROTOCOL/AGENTS.md`. **Read-only:** Go `codec/chunk_codec.go`, `codec/testdata/chunk-snapshot-v1.bin`, `protocol/snapshot.go`, `DOMAIN/src/sections.rs`. **Interfaces:** `ProtocolCodec::new() -> Result<Self,ProtocolError>`, `ProtocolCodec::decode_snapshot(&mut self,payload:&[u8])->Result<ChunkSnapshot,ProtocolError>` and `ProtocolCodec::encode_snapshot_into(&mut self,packet:&ChunkSnapshot,dst:&mut[u8])->Result<usize,ProtocolError>` are snapshot-only methods at this node; registry node 4.1 adds the public `ServerPacket` dispatch methods from design §1 after that enum exists. `ChunkSnapshot::encode_logical_checked(&self)->Result<Vec<u8>,ProtocolError>` is a bounded internal step; compact section conversion from 1.3 preserves palette/word arrays.

**Cases:** valid all-single 24 sections and mixed Single/Indexed4/Indexed8/Direct15 sections preserve dimension1, chunk−1/0, revision1, every Y0..23, palette order and packed words; `invalid-revision-zero`, 23 sections, Y order swap, palette index out of range, direct high bits set, compressed length 1,048,577, decoded length 2,097,153, truncated zstd frame, checksum failure and expansion beyond cap reject. Use the committed Go snapshot fixture as one decode case. A Rust-produced compressed block need not match Go bytes; Go must decode its logical result, Rust must decode Go's, and envelope length/checksum must be valid. **Red:** mutating `sections.pop()` after construction makes current `encode_logical` panic via `expect`; current `encode()` can panic on compression and has no caller buffer. **Implementation:** validate 24 compact sections and checked logical size before reserve; use `try_reserve` for explicit scratch allocations; zstd context is owned by one `ProtocolCodec`, with one call's scratch bounded by 1 MiB compressed and 2 MiB logical; check envelope lengths and destination before copying any byte. Decoder validates envelope, declared lengths, checksum and logical section shape before publication. The existing Go fixture is never overwritten. **Validation:** tasks commands plus `go test ./packages/shared/network/codec -run 'TestSnapshotBounds|TestWorstLegalLogicalSnapshot' -count=1`; measure allocation/performance only informationally. **Exclusions:** no per-cell boundary copy or save-codec migration. **Commit:** `feat(protocol): qualify bounded chunk snapshots`.
