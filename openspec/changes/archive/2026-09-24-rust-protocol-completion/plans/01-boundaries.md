# Boundary and evidence worker packets

All paths are repository-relative. `PROTOCOL` means `packages/engine/crates/mornlea_protocol`; `DOMAIN` means `packages/engine/crates/mornlea_domain`; `ORACLE` means `packages/tools/cmd/runtime-oracle`; `CORPUS` means `testdata/runtime-migration`. The source authority is current Go code and tests named in [wire-matrix.md](../wire-matrix.md); the accepted target meaning is in `DOMAIN`. These packets are implementation instructions, not completion claims. Only [tasks.md](../tasks.md) has status checkboxes.

For each packet group below, write a test that first fails against the current implementation for the named behavioral gap. Run the exact test command, then implement the prescribed boundary and rerun the Go producer plus Rust consumer; `-- --list` must show nonzero cases. A discovered Go/Rust difference returns to the controller for a design/spec/table ruling. Do not change production Go, live saves, default startup, or unrelated golden files. The controller reviews the red/green output, corpus asset diff and scoped commit before marking a node complete. Every node rolls back by reverting its Rust/API and matching test/corpus additions together while retaining accepted predecessor contracts.

## Shared packet-case contract

`protocol_corpus_helpers_test.go` provides `RunProtocolCases(root string, selection Inventory, routes map[ConsumerRoute]GoOperation) ([]ExecutedObservation,error)`. It rejects an empty selection, unknown `{family,version,operation}`, missing/duplicate checkpoints and any route not registered in the candidate; it calls existing `readCaseInput` and the existing normalized observation builder, never the expected result. `RunCases` remains a wrapper for the domain/Agent producers with its original signature and behavior. `ConsumerRoute` is the existing `{FamilyID,Version,Operation}` type. A group producer uses actual `codec.NewCodec().EncodeClient/DecodeClient/EncodeServer/DecodeServer` and `protocol.Validate*`; it may parse JSON input into a Go DTO but cannot implement a second encoder or validator. The positive decode case input is Go-encoded payload bytes; the positive encode case input is canonical JSON fields and the produced encoded bytes are compared to the Go output. A negative decode case mutates a valid Go payload; a negative encode case mutates a Go DTO before the production codec validates it. Each protocol case carries the complete `PacketKey` and one `decode` or `encode` operation. Normalized success uses semantic field names, decimal strings for u64/i64, eight-digit hexadecimal f32 bits, ordered arrays, and an encoded digest where bytes are comparable. Errors use the frozen category vocabulary, never localized messages. Snapshot compression compares logical output and decoder interoperability instead of compressed block bytes.

`tests/protocol_corpus.rs` registers `CorpusConsumer::Protocol` as `mornlea_protocol` for packet cases while retaining `CorpusConsumer::Frame`/`corpus_frame` for all three frame cases. It loads both selections and executes each selected case once per protocol-corpus pass with a nonempty operation and digest-verified input. The preexisting `runtime_contract` frame test remains a separate regression suite. Each group test calls `load_case(id)`/`assert_normalized` and its actual Rust decode/encode path; no Rust test launches Go. The following test-only selection and merger are produced in node 1.1:

```go
type ProtocolSelection struct {
    ProducerID string
    Cases []CaseSpec
    SourcePaths map[string][]string // family ID to repository-relative Go source paths
    Routes []ConsumerRoute
}
func mergeProtocolSelections(root string, base Inventory, groups ...ProtocolSelection) (Inventory, error)
```

The helper clones the frozen manifest, rejects conflicting/duplicate IDs and unregistered routes, updates only the selected protocol family case lists and hashes from the live source files, sorts IDs/sources and verifies `ReconcileWorking`. It preserves unrelated families/cases/digests and `source_revision`. Candidate assets and the complete merged manifest are exported with the existing create-exclusive external exporter, reviewed, then copied by the controller. Refresh source hashes for edited source files, but defer the single global source-revision refresh to node 4.3. The normalized error categories are fixed by failure boundary: incomplete bytes `truncated`, excess bytes `trailing`, noncanonical/overflow varint `invalid-varint`, declared size or destination shortage `capacity`, invalid enum/packet key/boolean tag `invalid-enum`, invalid UUID or canonical identity/name `invalid-identity`, range/finite/text-field violations `invalid-value`, unsupported current-version requirement `unsupported-version`, and checksum/compressed-stream corruption `integrity`. A producer checks that the real Go codec/validator rejects the case before publishing the category; a Rust consumer derives the same category from its actual error. No category is inferred from localized error text or copied from the expected asset.

The common red/green step for a group is:

```text
1. Add a named valid decode, valid encode and invalid case to the group table and producer.
2. Run the filtered Go producer and confirm its actual values; run the Rust group test and confirm its specified baseline mismatch (not merely a missing test file).
3. Implement only the packet modules owned by the group, using the fields and validation order in the wire matrix.
4. Export candidates outside the repo, review hashes/identities, integrate assets and manifest routes serially, then rerun both tests and the existing Rust protocol runtime_contract.
5. Report exact source/result SHA, IDs, discovered/executed count and changed files; after controller acceptance commit with the message given below.
```

The per-packet Rust pattern after node 1.2 is `validate` → checked `encoded_len` → capacity check → private `publish_packet`; `decode` performs bounded reads, `done()`, then validation. A public mutable field is rechecked on every encode. Fixed-array decoding uses an indexed array, not an intermediate Vec. `PacketKey` is attached by registry, not stored in the domain. Every group tests that `encode_into` leaves a short sentinel-filled buffer unchanged and that an invalid value wins over short-buffer capacity. Per-family valid/invalid case labels and concrete values live in the node tables and [wire matrix](../wire-matrix.md).

## 1.2 — Caller-owned framing and private writer

**Predecessor:** 1.1. **Deliverable:** borrowed first-frame read and untouched-output write for canonical framing; the private packet writer makes later encoding atomic. **Editable:** `PROTOCOL/src/frame.rs`, `varint.rs`, `bytes.rs`, `error.rs`, `lib.rs`, new `PROTOCOL/tests/protocol_frame.rs`, `PROTOCOL/AGENTS.md`. **Read-only:** `packages/shared/network/codec/{frame,codec_primitives}.go` and current Rust runtime_contract. **Interfaces:** `FrameRef<'a> { packet_id: u32, payload: &'a [u8], consumed: usize }`; `read_frame_ref(&[u8]) -> Result<FrameRef<'_>,ProtocolError>`; `write_frame_into(u32,&[u8],&mut[u8]) -> Result<usize,ProtocolError>`; private `publish_packet(length, dst, write)` with `SliceWriter`. Keep `read_frame`/`write_frame` as allocating wrappers using these paths.

**Red cases:** `[2,0,45,2,1,46]` consumes 3 and borrows payload at original offset 2; `[1,7]` accepts empty payload; `[0]`, `[0x81,0]`, sixth-byte prefix, body max+1, truncated ID and trailing incomplete body reject; body length exactly 2,097,152 admits while 2,097,153 rejects; destination `[0xa5;5]` for a six-byte frame remains unchanged and reports `OutputTooSmall{needed:6,available:5}`. Invalid frame size wins over short capacity. Canonical u32 varint boundary lengths are 1 for 0..127, 2 for 128..16383, 3 for 16384..2097151, 4 for 2097152..268435455 and 5 otherwise; fifth data bits above 0x0f and redundant zero groups reject.

**Implementation:** parse the prefix and body bounds with checked `usize` arithmetic before slicing; parse the ID from that bounded body and return a borrow. For writing, compute ID varint length plus payload length using checked arithmetic, check 1..=MAX_FRAME_BYTES, then capacity, then write canonical prefix/ID/payload into an exact prefix. `SliceWriter` stores a cursor and only supports fixed-width LE integers, canonical varint, bytes and finite f32 bits; it never allocates, validates a semantic field or exposes an unchecked public call. `publish_packet` restricts the writer to the validated exact prefix and verifies final cursor length in a debug assertion. `ProtocolError` adds `UnknownPacket`, `OutputTooSmall { needed, available }`, and `Allocation`; existing variants remain. **Validation:** commands in `tasks.md`, `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_protocol --test runtime_contract --locked`, and one allocation-count test for borrowed read after warm-up; the baseline `read_frame` ownership means the no-allocation borrowed case fails before implementation. **Exclusions:** no claim that zstd or all packets are allocation-free. **Integration/rollback:** controller serializes `lib.rs`; revert public API and test together if rejected. **Commit:** `feat(protocol): add bounded caller-buffer framing`.

## 1.3 — Shared values without raw-format loss

**Predecessor:** 1.2 and accepted domain-event successor. **Deliverable:** protocol uses domain-checked shared values while preserving raw wire exceptions. **Editable:** `PROTOCOL/src/{player_id,entity_id,item_stack,drop_id,container_ref,block,chunk_snapshot}.rs`, `PROTOCOL/src/lib.rs`, `DOMAIN/src/text.rs`, `DOMAIN/src/lib.rs`, new `PROTOCOL/tests/protocol_values.rs`, `PROTOCOL/AGENTS.md`, `DOMAIN/AGENTS.md`. **Read-only:** Go `core` item/UUID/section rules, Go `protocol/snapshot.go`, `DOMAIN/src/{identity,items,locations,sections}.rs`. **Interfaces:** reexport `PlayerId`, `CompanionId`, `ItemStack`, `DropId` from domain; wire `ContainerRef {dimension:i32,chunk_x:i32,chunk_z:i32,kind:u8,slot:u8,generation:u32}` with exact `NONE`, `to_domain_present` and `to_domain_optional`; `DOMAIN::trim_pinned_whitespace(&str)->&str`; checked compact section move conversion `TryFrom<SectionData> for PalettedSection` and `TryFrom<PalettedSection> for SectionData` with Y index supplied separately where needed.

**Red cases:** raw dimension 256 and −1 must reject rather than narrow to 0/255; exact all-zero container becomes `None`, but zero generation with nonzero coordinate is invalid; a public `MoveContainerStack` with bad real dimension/generation must later reject on encode; `CompanionId::NONE` cannot be an ordinary spawn/despawn identity; every registered item 0..65 has one domain-defined limit/durability rule, while item 66 fails; a valid indexed section keeps the exact palette and packed word order; U+200B remains untrimmed while U+00A0 and U+3000 trim. Current `ContainerRef::read` narrows i32 to u8 and the protocol owns duplicate item tables, so these are behavioral reds.

**Implementation:** use domain newtypes and item predicates instead of protocol tables. Keep raw container fields only in protocol; never construct domain `ContainerRef` from NONE. Implement `to_domain_present` by checking dimension 0 and kind/slot/generation through the domain constructor, and `to_domain_optional` by exact six-field equality first. Expose the existing pinned whitespace predicate through a slice-returning helper in domain; `DisplayName::try_from_canonical` remains strict and does not trim. Convert sections by moving boxed palette/words to/from Vec while preserving bits and cell order; do not expand 4096 cells. Keep armor-owned raw triples separate from ordinary `ItemStack`. **Validation:** commands in `tasks.md` plus full `mornlea_domain --test runtime_contract`; expect exact sentinel/dimension failures to turn green with no version change. **Exclusions:** no new gameplay validation in domain. **Integration/rollback:** controller owns shared reexports and updates any dependent packet modules mechanically; revert producer and consumer API together. **Commit:** `refactor(protocol): use checked domain values`.

**Predecessors:** 1.2, 1.3. **Deliverable:** Go-compatible pure Rust negotiation and the two inbound packet-family corpus routes. **Editable:** `PROTOCOL/src/{client_hello,login_start,admission}.rs`, `PROTOCOL/src/lib.rs`, new `PROTOCOL/tests/protocol_admission.rs`, new `ORACLE/protocol_negotiation_test.go`, new `packages/shared/network/protocol_admission_oracle_test.go`, reviewed `CORPUS/cases/protocol/{ClientHello,LoginStart}/` assets, their routes in `ORACLE/inventory.go`, `PROTOCOL/AGENTS.md`. **Read-only:** `packages/shared/network/login.go`, `packages/shared/network/login_test.go`, `packages/shared/network/protocol/packet.go`, `packages/shared/network/codec/codec_client.go`, `DOMAIN/src/text.rs`. **Interfaces:** exact `InboundHello`, `InboundLoginStart`, `validate_hello`, `admit_login`, `AdmittedLogin` and error enums in design §3; `ClientHello::decode_inbound` and `LoginStart::decode_inbound` are the typed inbound paths. The Go runtime-oracle producer executes the real codec/validator for ordinary valid decode, valid encode and malformed-decode cases for both families. Separately, the Go package-local admission test uses the existing `staticLoginStartStream`/Memory seams to observe `BeginServerLogin`; it does not import into runtime-oracle or export a duplicate corpus. **Red table:** version 44 structural hello → `VersionMismatch{server_version:45}`, not `UnsupportedVersion` from decode; zero UUID plus distance 1 → `InvalidIdentity`; valid UUID/name plus distance 1/65 → `ProtocolViolation`; valid UUID and `"  Alice  "` → admitted `"Alice"` and unchanged distance 2; 128 leading spaces plus `Alice` must first decode through the real Go inbound codec from a hand-built canonical payload and then admit through the Go login driver within the 64 KiB payload cap, while outbound raw name over 128 bytes rejects; 33 scalars after trim, control U+0001, invalid UTF-8, trailing byte, missing distance reject at their owning boundary. **Implementation:** decode structurally with canonical length and UTF-8 checks, retain raw identity/name/distance, then apply UUID → trim/canonical name → distance in that order. Add `protocol.client.ClientHello/45/{decode,encode}` and `protocol.client.LoginStart/45/{decode,encode}` routes through the shared packet-case runner. Ordinary malformed decode cases use mutated Go-valid bytes; old-version and long-raw-name admission cases remain in paired codec/driver and Rust semantic tests because Go outbound encoding rejects those values; the Go test hand-builds only the canonical invalid-inbound wire bytes, calls the production inbound codec, then passes its DTO into the existing stream seam. No live listener or save. **Validation:** commands in `tasks.md` plus `go test ./packages/shared/network -run 'TestServerLogin|TestProtocolAdmissionOracle' -count=1`; inspect both Go test suites and the Rust test for nonempty, matching case IDs. **Exclusions:** timeout, session attach and transport send remain F2. **Integration/rollback:** controller merges the two packet families and route table; revert Rust admission/API and both test-only Go evidence paths together. **Commit:** `feat(protocol): separate inbound admission from parsing`.

## 1.5 — Control packets

**Predecessors:** 1.1–1.4. **Deliverable:** the seven non-gameplay control packet families are fallible, corpus-backed and ready for typed dispatch. **Editable:** `PROTOCOL/src/{server_hello,handshake_reject,login_success,login_reject,keep_alive,keep_alive_reply,disconnect}.rs`, new `PROTOCOL/tests/protocol_control.rs`, new `ORACLE/protocol_control_test.go`, reviewed `CORPUS/cases/protocol/{ServerHello,HandshakeReject,LoginSuccess,LoginReject,KeepAlive,KeepAliveReply,Disconnect}/` assets, corresponding family routes in `ORACLE/inventory.go`, `PROTOCOL/AGENTS.md`. **Read-only:** Go `protocol/packet.go`, `codec/codec_client.go`, `codec/codec_server.go`, `codec/codec_golden_test.go`. **Interfaces:** each concrete packet gets the common fallible `validate/encoded_len/encode_into/encode/decode` surface in design §4; the control keys are exactly in the wire matrix, with no domain command/event conversion.

**Case table:** each family has valid decode + valid encode + a malformed decode or invalid encode case. `ServerHello` v45 succeeds and v44 rejects; `HandshakeReject` code 1/empty message succeeds and code 2 rejects; `LoginSuccess` zero seed succeeds and invalid UUID rejects; `LoginReject` codes 1 and 7 succeed, 0/8 reject, message 256 bytes succeeds and 257 rejects; `KeepAlive` and `KeepAliveReply` token 1 succeeds and 0 rejects; `Disconnect` code 1 and 5 succeed, 0/6 reject, message 256 succeeds and 257 rejects. For every fixed payload, test every proper truncation and one trailing byte. **Implementation:** use the common writer in field order; check enum/string bounds before size/capacity; keep `u64` little-endian and current reject code values. The group producer calls actual Go codec encode/decode for each key and records normalized fields. **Validation:** commands in `tasks.md` plus `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_protocol --test runtime_contract --locked`. **Exclusions:** login lifecycle and keepalive scheduling are server/client core policy. **Integration/rollback:** controller serializes corpus merge; revert this group's seven packet changes and cases as one node. **Commit:** `feat(protocol): qualify control packet codecs`.
