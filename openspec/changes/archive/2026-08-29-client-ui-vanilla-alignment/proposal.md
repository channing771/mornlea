# 客户端 UI 对齐原版布局与风格精修

## Why

用户目标是把图形客户端的 HUD、容器界面与 egui 菜单的布局对齐 Minecraft 原版的空间关系，同时以现代面板语言优化视觉风格。用户已裁决三个方向：范围取 HUD + 容器 + egui 全量；容器采用原版式浮动面板；风格走「混合：像素图标 × 现代面板」（深色半透明面板 + 1px 亮边 + 单一琥珀强调色）。

当前与原版的缺口：准星完全没有实现；切换选中栏位没有物品名弹条；容器是「自下而上贴着快捷栏堆叠」的行式布局而非原版的居中浮动面板；熔炉没有原版的「输入在上、火焰居中、燃料在下、箭头指向输出」图式；悬停无 tooltip（容器中辨认物品的唯一途径缺失）；HUD/容器/菜单三张皮没有统一的风格令牌。底栈骨架（快捷栏居中、生命锚左、饥饿镜像锚右、氧气外侧堆叠）已符合原版语法，本变更只收紧关系与补全元素，不推翻既有锚定契约。

## What Changes

- **生存 HUD**：底部边距 `hotbarBottomMargin` 24→6 收紧到原版关系；新增屏幕中心原创十字准星（深色投影 + 亮色前景双层矩形）；新增选中栏位确认变化的物品名弹条（40 权威 tick 窗口、仅消费确认镜像、容器与菜单相位抑制、零 quad）。
- **容器浮动面板**：背包/工作台/熔炉/箱子改为屏幕居中浮动面板（标题在顶、玩家背包 3×9 + 快捷栏行收进面板下段）；熔炉用原版图式（输入上、火焰中、燃料下、箭头指向右侧输出）；个人背包面板以右侧栏保留既有十条固定配方入口（对齐原版配方册的刻意分歧，命中下标不变）；新增悬停 tooltip 显示物品中文名；绘制与命中共用同一面板几何源。
- **egui 菜单**：主菜单/暂停/设置/F3 统一深色半透明面板 + 1px 亮边 + 琥珀单一强调色；wire layout v1–v4、动作钉值与全部行为语义不变。
- **图标精修**：心/鸡腿/气泡/火焰/箭头/凹槽等既有 atlas mask 就地重绘提净，不新增图集列、不改变既有 cell 列界。
- **资源契约重钉**：`maxHotbarQuads` 267→320、`maxHotbarGlyphs` 700→768、glyph offset 13312→15616、固定上传总容量 46912→52480；benchmark scenario v19→v20（README 版本矩阵、compatibility、architecture 与相关注释同步）。
- **视觉验证**：capture 场景 23→24（新增 `hud-item-name-popup`，位于 `hud-survival-feedback` 之后）；HUD 样式、容器面板与菜单换肤波及全部既有 golden，显式更新并逐图人工复核。

## Impact

- **specs**：
  - `survival-hud-presentation`：MODIFIED「生存 HUD 在窄 framebuffer 内整体等比缩小」「生存 HUD 保持固定资源和实例兼容性」；ADDED「准星以屏幕中心十字呈现」「选中栏位变化以物品名弹条呈现」。
  - `container-ui-presentation`：MODIFIED「三类容器使用统一的原创像素表面」「容器换肤不改变统一栏位和权威交互」「容器像素换肤保持固定 HUD 资源契约」；ADDED「悬停栏位以 tooltip 呈现物品中文名」。
  - `visual-verification`：ADDED「选中弹条无窗口场景」（23→24 口径）。
- **不变**：协议、玩家/区块 schema、world metadata、engine ABI、client ABI、配置版本、存档格式均不变；`egui-tool-ui`、`settings-menu`、`debug-panel` 主规格不携带 delta（其要求钉行为与布局关系，不钉颜色；换肤不改变任何被钉语义）。
- **交互语义不变**：栏位下标集合、两次点击整堆移动、产物单击取出、Esc 栈、容器打开时的输入抑制、权威镜像消费边界全部保持。
- **美学护栏**：全部像素继续由本项目原创程序化绘制，MUST NOT 导入、临摹或复制 Mojang 资产；单一琥珀强调色；零 em-dash。
