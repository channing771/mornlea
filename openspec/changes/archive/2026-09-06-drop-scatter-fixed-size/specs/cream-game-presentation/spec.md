# drop-scatter-fixed-size Delta

## Purpose

把同格掉落散列从“按密度缩小防重叠”改为“全尺寸恒定、允许轻微交叠、可辨认为先”：用户已明确接受小小重叠。布局骨架（分组、排序、唯一 cell、抖动、分层、容量、支撑、生命周期）全部保留，只改尺寸与两条随之放宽的几何断言。

## MODIFIED Requirements

### Requirement: 掉落稳定分散且非方块保留轮廓

同方块内每个权威掉落堆 SHALL 仅产生一个实例，通过稳定身份和当前集合在原方块 XZ 范围内分散，分散缩放恒为 1（1/4/16/32 堆同一尺寸）。常规稀疏组合 MUST 有随机感；高密度组合 MUST 使用分层保持可辨，允许保守包围体轻微交叠。XZ 在 4 堆及以下 MUST 不越原方块，16/32 堆因全尺寸允许边缘探出但 MUST NOT 超过 0.14 格（6×6 档边角中心 0.875 加薄片半宽 0.25 加最大抖动 0.006 的推导上界 0.131，取 0.14 裕量）。非方块 MUST 使用透明轮廓的双面直立薄片，方块保留微缩立体表现。位置与动画 MUST 可重放，不改变服务端拾取、合并、数量或存档。

#### Scenario: 全密度固定尺寸与重放

- **GIVEN** 同格 1、4、16、32 个混合类别堆及重排的同一集合
- **WHEN** 渲染相同 tick
- **THEN** 全部实例缩放 MUST 为 1，输出按身份 MUST 确定，数量不丢失且不超固定容量

#### Scenario: 稀疏不越界、密集探出有界

- **GIVEN** 同格 1、4、16、32 个混合类别堆
- **WHEN** 渲染全部自转相位
- **THEN** 1/4 堆 XZ MUST 不越原方块且相邻堆交叠轻微；16/32 堆 XZ 探出 MUST NOT 超过 0.14 格

#### Scenario: 支撑与生命周期

- **GIVEN** 关联死亡或失去支撑的掉落物
- **WHEN** 分散呈现与下落/死亡渐显同时生效
- **THEN** 隐藏的死亡前期堆仍占位，支撑锚定与离地间隙语义 MUST 与改前一致
