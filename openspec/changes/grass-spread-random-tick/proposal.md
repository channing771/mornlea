# 草方块随机 tick 蔓延

## 背景

泥土块紧邻草方块时没有任何蔓延机制：`advanceCropCell` 的随机 tick 分支链只覆盖作物、干农田回退、树苗与积雪，泥土永远是泥土（唯一的草变泥转换是牛吃草）。用户期望经典体素语义：表面泥土在草方块邻接时逐渐转为草。`docs/feature-backlog.md` 在 E-19 处已预留「草蔓延」挂载面。

## 目标

- 随机 tick 命中表面泥土（上方为空气或季节雪覆盖、四个水平邻格中至少一个为草方块）且骰子命中时，将该格转为草方块。
- 转换经既有 `Dimension.SetBlock` 加 `Mutation.Record` 写回，客户端经既有块变更流获得同步，无新协议面。
- 判定确定性：采样与骰子沿用 `server/updates` 采样器纯函数形态，新增独立盐；读预算有界。

## 非目标

- 不做草的退化/死亡（被遮挡变泥）；不为蔓延加光照条件（服务端无光照系统，天空暴露代理留待后续）。
- 不改变世界生成期的草分布（`natural-grass-generation` 现状）。
- 不涉及协议、存档 schema 或 engine ABI。

## 用户可观察结果

- 玩家放在草地旁的表面泥土会在数分钟量级内变成草方块；被牛吃秃的草皮在邻接草存在时同样恢复。
- 季节雪覆盖下的蔓延语义按设计文档裁决执行（允许，雪视作非实体遮蔽）。

## 受影响包

- `packages/server/sim/realm`（随机 tick 分支与测试）
- `packages/server/updates`（采样器盐与 KAT）

## 兼容性影响

无协议/存档/ABI 变更。行为增量：世界自发生成草变泥土的块变更并流式同步；读预算每检查格至多 5 次方块读。
