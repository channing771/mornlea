## MODIFIED Requirements

### Requirement: 三类容器使用统一的原创像素表面

系统 SHALL 经前端组件为背包/个人合成、工作台、箱子与熔炉呈现统一奶油浮动面板。面板、标题、槽位、配方与进度 MUST 经前端令牌供给，原有网格与熔炉输入/燃料/输出流程语义保留，绘制与点击共用 DOM。GPU 不再负责面板。

#### Scenario: 背包与合成使用像素框和程序化标题
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 个人面板 MUST 呈现 2×2 合成、产物、三排背包与独立底部快捷栏共 36 玩家栏位、十条只读配方选择与材料预览；所有元素由前端奶油组件绘制，状态栈避让。

#### Scenario: 熔炉使用像素流程图示
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 熔炉 MUST 呈现上层输入、下层燃料、火焰、指向输出的箭头与权威进度；前端裁剪填充不得伪造进度。

#### Scenario: 箱子使用同一像素语言
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 箱子 MUST 呈现 27 箱子格与 36 玩家格，使用同源前端组件与来源标识。

### Requirement: 容器换肤不改变统一栏位和权威交互

系统 SHALL 保留所有现有权威栏位编号与命令。前端只发送语义操作，Go MUST 校验相位、当前视图身份与索引后调用既有整堆移动路径。第一次点击记录来源，第二次点击目标只发送一次请求并清除来源；确认前不改镜像。DOM 槽位是命中单源，装饰及 tooltip 不得扩大或遮挡点击。

#### Scenario: 普通背包保持 36 格与十条配方命中
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 前端 MUST 呈现 36 玩家栏位与十条既有配方，DOM 点击与相应语义编号一一对应。

#### Scenario: 熔炉保持 39 格两次点击整堆移动
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 熔炉 MUST 保留 39 格统一语义；第二次有效点击后仅发送现有容器移动请求，确认前镜像逐格不变，输出格不得作为输入目标。

#### Scenario: 箱子保持 63 格两次点击整堆移动
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 箱子 MUST 保留 63 格统一语义；第二次有效点击后仅发送现有容器移动请求，确认前镜像逐格不变。

### Requirement: 容器像素换肤保持固定 HUD 资源契约

面板迁至前端后，生产帧 SHALL 不再产生容器或 tooltip 的 HUD GPU 实例。原有 48-byte 编码、320 quad、768 glyph、15616 bytes glyph offset、52480 bytes 上传容量与 256 bytes 对齐 MUST 保持兼容，不得以迁移放宽 overflow。稳定态图像素材 MUST 复用缓存，禁止每帧动态 GPU 资源。无头路径不以 GPU fallback 重现面板，面板视觉验证使用前端 fixture。

#### Scenario: 最大打开态仍装入 scenario v20 固定缓冲
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 容器、标题与 tooltip MUST 产生零 GPU quad/glyph；固定兼容容量、offset、编码和对齐保持不变。

#### Scenario: 最大打开态加入 marker 仍不扩容
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 权威 marker 由前端呈现，MUST 不增加 GPU 面板实例或扩大容量。

#### Scenario: 零尺寸与窄窗口不引入资源或边界例外
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 零尺寸 MUST 不呈现；窄窗口前端布局 MUST 保持内容可访问、命中与 DOM 一致且不新增 GPU 资源。

### Requirement: 悬停栏位以 tooltip 呈现物品中文名

前端 SHALL 在悬停或键盘聚焦非空栏位、产物或配方产物时显示中文名 tooltip，名称经 Go 既有注册表下发。tooltip MUST 使用奶油面板令牌、限制在视口内且不参与指针命中。空格、面板外或关闭后 MUST 隐藏。

#### Scenario: 悬停有物格显示名称
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 前端 tooltip MUST 显示该物品中文名且被约束在视口内，不遮挡点击。

#### Scenario: 空格与面板外无实例
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 前端 MUST 不显示 tooltip，GPU MUST 不产生 tooltip 实例。

#### Scenario: 名称来源与弹条同源
- **GIVEN** 已确认且符合本场景的容器状态
- **WHEN** 前端呈现并接收对应交互
- **THEN** 两者 MUST 使用同一注册表显示名来源且文本一致。
