## Context

HUD 已在 React，容器/tooltip 仍在 Go HUD 实例流；WebView 游戏态全穿透导致无法直接点击。现有 Go 点击函数复用权威命令但以 GPU 坐标命中。角色六个 cuboid 共用 450 实例容量，掉落每堆一个实例且每区块最多 32 堆。动机见 proposal.md。

## Goals / Non-Goals

目标是所有面板前端绘制并可操作、物品素材同源、人物与掉落更精细。保持网络/存档/C ABI 布局与固定资源上限；不新增玩法、物理坐标存储或外部服务。

## Decisions

1. 前端是面板布局、命中和 tooltip 的唯一来源，UI下行视口使用CSS逻辑点（窗口ContentSize），世界FramebufferSize仍为物理像素；2x屏不能用物理宽度缩放CSS HUD。Go 下发语义快照（视图身份/网格/产物/玩家栏位/配方/进度/来源），上行发送语义索引与视图身份。Go 校验后复用既有命令路径，不接受前端提供的物品内容，不用虚构坐标调用旧命中函数。人物页仅展示已有玩家状态与原创肖像。十条现有配方原来只供展示/tooltip，未有网络选择命令；迁移后点击只读高亮与材料布局，不自动填料。淘汰生产 GPU 面板与命中调用；无头捕获不提供旧 GPU fallback，面板视觉改用前端 fixtures。
2. 保留 Menu/GameOverlay 两个本地枚举含义，Menu 扩展为交互参与态。捕获光标时透明穿透；面板或自由光标时前端接管。既有释放入口如不足则增加清晰的 Tab 切换；前端关闭、E/Esc/数字键由受限事件返回 Go，防止 WebView 吞掉原生键位释放。游戏输入在切换时中和，恢复重建鼠标基线。-connect 是交互窗口，须支持同一 UI；benchmark/capture 保持无 WebView。
3. 所有快照数组有界，schema 先行并同步 Go/TS/Rust。视图身份在开关/容器变化时变更以拒绝滞后事件。物品值只读镜像；本地来源/光标状态变化可以立即推送，权威 HUD 仍按 tick 合并。前端不做库存预测、合成计算、持久化或网络请求。
4. assets 提供原创建模像素图（工具/食物/矿物等透明轮廓）和物品层映射。UI 使用同一 registry 图像在装配时生成的有界缓存图标目录；通过桥或受控内嵌资源提供给前端，不能逐 tick 编码图像。方块使用活动材质，未知 ID 明确缺失；非方块掉落只更换材质层，沿用 alpha cutout 双面薄片。避免独立画两份无法同步的 SVG/PNG。
5. 人物保持六件身体与固定实例预算，利用原创建模纹理/面向 UV 增加脸、发型、领口、袖口、裤装、靴子。面部只朝前，侧后面取头发/肤色，不能复制脸到所有面。材质层与 shader 同步但 C ABI 96-byte 实例布局不变。XZ 距离驱动步态，周期距离由腿长与幅度推导；垂直运动不累计，同 tick 插值持续累计，超界传送和回退清零。
6. 掉落按方块分组、稳定 ID 排序后分配槽位，以哈希做槽内小扰动，位置限定原方块 XZ。稀疏按保守旋转包围体留间距，高密度使用缩放与分层，32 堆上界下检测所有包围体不相交。每堆始终独占 XZ cell（最多6×6），分层不复用水平位置，避免不同出生年龄在下落途中穿插；网格可用宽0.9、抖动上界4% cell，保守旋转半径0.251，尺寸不超过84% cell的直径。每堆仍仅一个实例，不改变权威合并/拾取；死亡缩放与原支撑下落叠加，漂浮幅度纳入层间净空。删除堆可导致剩余堆重新排布，此取舍换取重放与观察顺序无关。

## Risks / Trade-offs

- 原生焦点切换遗留按键 → 测试切换前按住移动/鼠标，切换时清理状态与重建鼠标基线。
- UI 消息体过大 → 图标预生成并复用，消息/数组有界，在现有桥容量内验证最坏组合。
- 奶油底色与物品对比 → 深可可文字、图标描边，状态数字不被选中抬升裁掉。
- 散落是纯呈现偏移 → 拾取仍按原方块中心；偏移不越原方块，保留既有玩法。
- 稠密缩小影响远处可辨性 → 普通少量保持较大尺寸，仅高密度按容量缩小；不会隐藏实例。
- 历史规格存在旧 GPU 数字 → delta 明确前端迁移，固定 C 资源容量保持兼容，清理生产调用与更新相应门禁。

## Migration Plan

按面板/交互、素材、人物/散落、整体验证四个独立提交组逐项开发审查。每组先失败测试，再实现与定点验证。最后运行前端、Rust、Go 全量 race/vet 与 OpenSpec strict，并查看前端/UI、world 与运动捕获；变更未获发布请求不推送或合并。回退为撤销本变更提交，无数据迁移。
