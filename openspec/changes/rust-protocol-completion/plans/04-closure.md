# Registry, semantic bridge and acceptance packets

These packets consume all accepted packet groups and the [design](../design.md). `tasks.md` is the sole status source. No F2/F3 online process is launched here. The controller integrates shared files, checks current Go/Rust sources against the wire matrix, and records every ruling and nonempty test count in `ledger.md` before marking a node done.

<a id="node-4-1"></a>
## 4.1 — Closed direction/state registry

**Predecessors:** all nodes 1.4–3.11. **Deliverable:** one public typed Rust API accepts exactly the 59 Go v45 packet keys and reaches every real decoder/encoder. **Editable:** new `PROTOCOL/src/registry.rs`, `PROTOCOL/src/lib.rs`, `PROTOCOL/src/codec.rs` from 3.2, new `PROTOCOL/tests/protocol_registry.rs`, `PROTOCOL/AGENTS.md`; controller alone merges the final route table into `ORACLE/inventory.go`. **Read-only:** Go `packages/shared/network/protocol/registry.go`, `packet.go`, `codec/chunk_codec.go`, frozen `CORPUS/contracts.json`. **Interfaces:** exact `Direction`, `State`, `PacketKey`, `ClientPacket`, `ServerPacket`, `decode_client`, `encode_client_into`, `ProtocolCodec::decode_server/encode_server_into`, and `key()` methods from design §1. `ClientPacket` uses raw `InboundHello` and `InboundLoginStart` for the two inbound negotiation variants; all other variants contain their corresponding concrete packet type. `ServerPacket` has all 36 server variants. The codec owns its snapshot context and does not borrow a transport.

**Registry map:** C/Handshake:0 ClientHello; C/Login:0 LoginStart; C/Play:0 PlayerInput, 2..21 exactly as the client table in the wire matrix (ID1 reserved). S/Handshake:0 ServerHello,1 HandshakeReject; S/Login:0 LoginSuccess,1 LoginReject; S/Play:0..31 exactly as the server tables in the wire matrix. Numeric IDs collide across direction/state by design; the complete three-part key is unique. `ContainerClosed` S/Play/14 must be publicly reachable. `ClientPacket::key` and `ServerPacket::key` agree with the decoder's matched key and the Go registry for all 59 variants.

**Red cases:** currently no typed dispatch exists. Register one real Go-produced valid payload for every key in a table and call actual Rust dispatch; the baseline cannot decode through that boundary. For each key mutate only direction or state and require `UnknownPacket` or the corresponding closed rejection; C/Play/1, C/Play/22, S/Play/32, unknown state byte4 and a Login payload with a Play ID must fail. Delete one key from a test-owned expected table, duplicate one complete key, and swap one server ID; the comparison must fail by key/variant, not only by count. Decode old-version ClientHello structurally and obtain the v45 mismatch through `validate_hello`, not an early payload error.

**Implementation:** use exhaustive matches over `(state,id)` separately for client and server, calling the already accepted concrete packet decoder; no string-based module lookup, `Box<dyn Packet>`, generic catch-all variant or fallback. `encode_*_into` pattern matches the typed variant, obtains the packet's key, validates and delegates to its `encode_into`; server snapshot delegates to `ProtocolCodec` scratch. A packet with wrong requested state cannot be encoded under that state because no state argument exists on output. Rust types and enums are public; private helper tables may be generated from a reviewed literal map, but the runtime never reads the Go source or test manifest. **Validation:** tasks commands plus `rustup run 1.97.1 cargo test --manifest-path packages/engine/Cargo.toml -p mornlea_protocol --test runtime_contract --locked`; inspect `-- --list` for all 59 case names. **Exclusions:** no socket, session transition or Godot bridge. **Integration/rollback:** controller owns `lib.rs` and context merge; revert registry/codec dispatch as one unit, leaving independently accepted concrete codecs intact. **Commit:** `feat(protocol): close typed packet registry`.

## 4.2 — Exhaustive wire-to-semantic adapters

**Predecessors:** 4.1 and accepted `mornlea_domain` event surface. **Deliverable:** F2/F3 consume checked semantic values with no packet-byte or authority metadata leakage. **Editable:** new `PROTOCOL/src/semantic.rs`, `PROTOCOL/src/lib.rs`, new `PROTOCOL/tests/protocol_semantic.rs`, `PROTOCOL/AGENTS.md`. **Read-only:** `DOMAIN/src/{input,event}.rs` and their submodules; `DOMAIN/tests/{command_control,command_inventory,event_surface,event_chat}.rs`; Go ingress/publication files listed in the wire matrix. **Interfaces:** `PlayIntent::{Sequenced{sequence:u64,command:DOMAIN::Command},Chat(DOMAIN::ChatIntent),KeepAliveReply{token:u64}}`; `TryFrom<ClientPacket> for PlayIntent`; `TryFrom<ServerPacket> for DOMAIN::Event`; `TryFrom<DOMAIN::Event> for ServerPacket`; `TryFrom<PlayIntent> for ClientPacket` for F3 output. Conversion errors use `ProtocolError` with explicit mappings, and no conversion invents `session`, `tick`, `arrival_index`, routing recipient or authoritative result.

**Client map:** `PlayerInput`, `PlaceBlock`, `RequestChunkResync`, `SelectHotbar`, `MoveInventoryStack`, `MoveCraftingStack`, `OpenContainer`, `MoveContainerStack`, `CloseContainer`, `DropSelectedItem`, `TillSoil`, `BoneMeal`, `TakeCraftingOutput`, `CollectWater`, `PlaceWater`, `EquipArmor`, `MoveStackPartial`, `QuickMoveStack`, `DropStack` each map to exactly one `DOMAIN::Command` variant. `ChatCommand` maps only to `Chat`, `KeepAliveReply` only to `KeepAliveReply`. Handshake and Login packets have no `PlayIntent`. On reverse conversion, sequence is placed only in packets that carry it; Chat has no sequence.

**Server map:** `ChunkSnapshot`, `BlockChanges`, `ForgetChunks`, `PlayerState`, `CommandRejected`, `RemotePlayerSpawn`, `RemotePlayerDespawn`, `RemotePlayerStates`, `InventoryState`, `ItemDropUpserts`, `ItemDropRemoves`, `FurnaceState`, `ContainerClosed`, `ChestState`, `ChatEvent`, `CompanionSpawn`, `CompanionStates`, `CompanionDespawn`, `PlaceBlockSucceeded`, `CraftingState`, `HostileSpawn`, `HostileState`, `HostileDespawn`, `CombatHit`, `PassiveSpawn`, `PassiveState`, `PassiveDespawn`, `ProjectileSpawn`, `ProjectileState`, `ProjectileDespawn` map to the same-named 30 checked `DOMAIN::Event` variants (`ChatEvent` maps to `Event::Chat`). `ServerHello`, `HandshakeReject`, `LoginSuccess`, `LoginReject`, `KeepAlive` and `Disconnect` must reject conversion. Reverse conversion checks each wire count cap (4 companion, 7 remote player, 32 drops, 64 hostile/passive, 128 projectile, 4096 world deltas/forget) before copying or encoding; a domain-valid 4096-record mob batch rejects as one packet rather than truncating. `RoutedEvent` recipient stays outside `ServerPacket`.

**Red cases:** current crate has no semantic adapter; a test must construct all 19 domain commands, all 30 event variants and the two control exclusions and call the public conversion (baseline import fails), but that alone is insufficient: add a concrete 5-record companion domain batch and assert one-wire conversion rejects before the implementation, plus a nonzero raw container reference with dimension256 that must fail rather than alias. Construct a chat invalid-format branch with exact absent ID and verify `None`, then a valid companion branch and verify checked ID. Mutation tests change each of `sequence`, world dimension, actor health, record order, chat kind and reject reason in a normalized expectation and require comparison failure. `DOMAIN::CommandEnvelope` is not constructed by any conversion.

**Implementation:** use exhaustive `match` arms with field-by-field conversion and owned moves for Vec/Box payloads; validate existing domain constructors on the way in, not a copied protocol rule. Convert raw sentinel through 1.3's checked API. Map reject reasons through 3.3's closed table, not `as u8`. For chunk sections use 1.3's compact move conversion; do not call `block_at` 98,304 times. For every batch compare length to the packet cap before copying; preserve source order. `PlayIntent::Sequenced` and reverse conversion are the only places the wire sequence is detached/reattached. **Validation:** tasks commands plus `cargo test -p mornlea_domain --test command_inventory --locked` from `packages/engine`; the Rust test enumerates every arm and reports executed counts. **Exclusions:** server command ordering, visibility projection, chat FIFO and persistence are F2. **Integration/rollback:** controller owns `lib.rs` export; revert semantic adapter without reverting accepted wire codec/registry. **Commit:** `feat(protocol): bridge packets to semantic values`.

## 4.3 — Protocol-only zero-gap evidence

**Predecessors:** 1.1–4.2. **Deliverable:** all 60 `protocol.*` family/version points have actual Go producer and Rust consumer execution; other F1 gaps remain visible. **Editable:** `ORACLE/inventory.go`, new `ORACLE/protocol_coverage_test.go`, `ORACLE/AGENTS.md`, `PROTOCOL/tests/protocol_corpus.rs`, `packages/engine/tests/runtime_corpus.rs`, `packages/engine/tests/AGENTS.md`, reviewed `CORPUS/contracts.json` and new protocol case assets, `PROTOCOL/AGENTS.md`, this change's `ledger.md`. **Read-only:** production Go protocol/codec, accepted domain event corpus and main `openspec/specs/rust-runtime-foundation/spec.md`. **Interfaces:** `TestProtocolCorpusComplete` runs `ReconcileWorking` with the closed consumer routes and asserts `Uncovered` contains zero `protocol.*` entries; Rust `protocol_corpus` executes every selected packet case and frame case exactly once. The final source revision equals `BaselineSourceRevision` and is a commit SHA preceding the corpus closure that contains the Go producers and source code.

**Acceptance table:** exactly 59 packet families and one frame family discovered independently from the Go registry/manifest; each packet family has >=1 valid decode, >=1 valid encode and >=1 invalid/boundary case (>=177 packet cases); frame has its two existing cases plus a real encode case (>=3), so protocol cases total >=180. Count all selected cases and checkpoints; zero-case, duplicate ID, missing route, missing source hash, altered packet key, wrong direction/state, wrong version, unexecuted case and mismatched digest each fail. Mutate one value in every packet *group* and one registry key, then require actual Rust comparison failure, not a pre-test manifest parse error. A separate test changes a Go source byte in a disposable copy and requires provenance rejection. Existing domain/Agent cases and their digests remain unchanged. `ReconcileWorking` may still report storage/kernel uncovered; `ReconcileComplete` for all F1 remains red until later successors.

**Implementation:** enumerate `protocol.*` from live Go discovery and assert exact set/key equality to the manifest and Rust enum table. Register `{family,"45","decode"}` and `{family,"45","encode"}` routes for all packet families, plus frame routes. Use the existing external create-exclusive exporter and reviewed manifest merge; no tracked writer. Refresh each touched source hash and then set `source_revision`/`BaselineSourceRevision` once to a verified implementation commit SHA; rerun every preexisting domain consumer and validate source provenance. The ledger records the SHA, aggregate and per-family case counts, executed/discovered tests, command output and exact non-protocol uncovered list. **Validation:** tasks commands plus `go test ./packages/shared/network/... -race -count=1`, `go test ./packages/audit -count=1`, and `git diff --exit-code -- testdata/runtime-migration` after the final reviewed corpus commit. **Exclusions:** never mark complete F1 or F2. **Integration/rollback:** controller owns manifest/source revision and can revert only this closure registration while retaining accepted packet groups; do not delete accepted source-bound cases without a new ruling. **Commit:** `test(protocol): close executable v45 corpus coverage`.
