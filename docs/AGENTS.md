# 文档指南

## 当前事实与历史证据

- 当前可观察行为由代码、测试和 `openspec/specs/` 决定。
- `docs/architecture.md` 描述当前架构，`docs/notes/progress.md` 记录实现编年史。
- `docs/superpowers/` 与归档 change 只作历史证据，不批量现代化，也不覆盖已核实的当前事实。

## 编写规则

- 长期基线只陈述当前事实；单个 change 的非目标留在对应 proposal，不写入长期入口。
- 文档、测试说明和开发者文本优先使用中文；外部 API、标识符和约定俗成的技术术语保留英文。
- 修改链接或命令前核对目标确实存在、命令与当前实现一致。
- 导航入口只链接权威正文，不在 README、索引和历史文档之间复制同一段说明。
