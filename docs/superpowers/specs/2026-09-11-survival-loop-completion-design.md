# 生存闭环收尾战役设计

日期：2026-09-11

## 1. 背景与裁决

2026-09-11 用户裁决：在开任何新方向（红石、完整生物群系、多维度世界等设计候选）之前，先把一个已有方向做到最完善。本设计把该裁决落到「基础生存玩法」方向——近期产品边界「首夜生存 + 自给家园」自 2026-08-26 重排以来已沿发布列车交付十行，方向本身已成型，剩余工作不是发散的新能力，而是把已有闭环的洞逐个补上。

「最完善」的判据不需要新发明：移除初始材料包的变更（归档 `archive/2026-09-11-survival-empty-start`）在 `packages/server/sim/entity/reachability_closure_test.go` 立了双向报红的价值闭包守卫，`acceptedUnobtainableItems` 显式记名了当前规则表下没有自然来源的物品。清空这份清单、补齐工具与战斗矩阵、打开地下世界，就是本战役的完成定义。

本设计是规划层产物：不认领任何行、不改变任何行状态、不预占任何版本号。各行仍按 `docs/feature-backlog.md` 的认领规则与串行链逐行推进，绝对版本号按各行实现时的 `main` 确定；本文只提供分组、依赖排序、裁决建议与验收口径。

## 2. 已核实现状（2026-09-11，main `49fb5fcd`）

- **价值闭包缺口九项**：`acceptedUnobtainableItems` 记名圆石、平滑石、苔藓圆石、白色羊毛、红色瓦块、马铃薯、胡萝卜、毒马铃薯、骨粉。前五项对应装饰材料自然获取行，中间三项对应作物物品自然来源行，骨粉对应骨粉获取路径行；三行均已排队，从未开工。
- **工具与战斗矩阵是半成品**：镐与锄只有石/铁两档，剑有木/石/铁三档；没有斧、铲、护甲物品，也没有任何远程武器与投射物。
- **矿物只有煤与铁两种**，且没有洞穴 carve——采掘纵深停留在地表浅层。
- **难度系统不存在**：配置与存档均无难度项，难度行自建表起排队。
- **B-42 潜行在途**：实现与评审已完成、PR 待合入（合入后协议升版）；战役各行自然排在其后。

## 3. 目标与非目标

### 3.1 目标

- `acceptedUnobtainableItems` 清空为空切片：注册表内每个物品都有自然来源，清空只能来自真实来源而非删声明（守卫双向报红保证）。
- 工具、武器与防具矩阵补齐：斧铲、护甲、远程武器落地，与既有镐锄剑构成完整矩阵。
- 难度分支可用（和平/普通/困难的差异化行为）。
- 地下世界可达：基础洞穴暴露煤/铁矿物，采掘纵深成立。
- 起家链路从「石镐」延伸到「铁器时代」全程无后门（沿 `survival_bootstrap_e2e_test.go` 先例）。

### 3.2 非目标

- 不开新方向：红石、完整生物群系、多维度世界、附魔药水、村民交易、骑乘矿车等一概不在本战役范围（用户裁决：先完善已有方向）。
- 不动「服务端不计算光照」禁令：敌怪生成维持时间门控，按黑暗生成属另一战役的前置裁决。
- 不新增生物群系与结构生成：装饰材料与作物来源只做最小自然来源裁决。
- 不做通用工具组件系统、拖拽铺放或自动整理（各行范围冻结时已有的排除项继续有效）。

## 4. 战役结构：三阶段十一行

串行链骨架沿既有依赖：难度 → 护甲 → 远程 → 分堆 → 斧铲 → 洞穴；价值闭包三行不占串行槽，按版本互斥与文件冲突规则择机插入。

| 阶段 | 行 | 交付 | 关键依赖与裁决 |
|---|---|---|---|
| 一：难度与战斗补全 | 难度系统 | 难度字段与差异化分支（困难饿死、和平回满、刷怪门控） | 先裁决孤儿分支（§5） |
| | 护甲 | 伤害减免、护甲槽位与 HUD 护甲条 | 依赖难度行 |
| | 远程敌怪与投射物 | 弓箭、投射物协议与命中模型、远程敌怪 | 依赖护甲行；与「第二类敌怪 AI/ECS 共享边界」评估一并执行 |
| 二：物品与工具补全 | 完整分堆与快捷搬运 | 容器半组/单件与快捷搬运 | 依赖远程行 |
| | 斧与铲 | 木/石/铁斧铲的配方、采掘速度与耐久 | 依赖分堆行 |
| | 采掘耕地连带收获 | 采掘半边同形结算（微型行，可搭任何一班） | 无 |
| 三：地下世界与闭包清零 | 基础洞穴生成 | 单一确定性 carve 竖切，旧区块不改写 | 依赖斧铲行 |
| | 装饰材料自然获取 | 圆石/平滑石/苔藓圆石/白色羊毛/红色瓦块的自然来源 | 与洞穴行一并裁决 worldgen 边界 |
| | 作物物品自然来源 | 马铃薯/胡萝卜/毒马铃薯的自然来源 | 无硬依赖 |
| | 骨粉获取路径 | 骨头来源与骨头→骨粉配方 | 落地时裁决「骨头从哪来」 |
| | 熟马铃薯与熟胡萝卜 | 两种烤制食物与熔炉配方 | 无硬依赖 |

规模感：近三行先例为六至十任务组（树苗再生八组、空背包六组、统一调度器十组），本战役十一行合计约三到四个该量级，跨若干周。阶段边界即门禁边界（推送前全量 `test-race` 与 `openspec validate --all --strict`）。

## 5. 孤儿分支裁决建议（难度行）

**事实**（2026-09-11 核实）：

- 分支 `feat/B-11-authoritative-difficulty`（worktree `.worktrees/B-11-authoritative-difficulty`，头 `95f733f0`，最后活动 2026-08-28），十三个提交、八十一个文件、+1556/−198 行。
- merge-base `1fbb6bdb` 是 B-30 时代（PR #103 合入前后）的 main，早于仓库单元化重构：分支全部路径为 `internal/core`、`internal/server`、`internal/sim`、`internal/storage`、`cmd/mornlea*`，这些路径在现行 main 上已不存在。
- 分支含全套 OpenSpec change（proposal/design/tasks 与三份 delta），提交记录显示已走过评审修复轮。
- 分支把难度写进世界 metadata v3；现行 main 的世界 metadata 为 v5，该槽位已不可用。
- 积压表明示本行维持排队、认领人空缺，裁决权在控制会话。

**建议：不收编代码、收编设计。** 理由：路径层面 rebase 不可行，语义移植的成本与重做相当；版本槽位已过期，任何移植都要重钉；实现规模本身不大，而设计论证、边界与评审记录已沉淀在 change 产物里——这正是可复用的部分。处置：

1. 以该 change 的 OpenSpec 产物为设计输入重新认领实现，难度字段按届时 main 取下一 metadata 版本。
2. worktree 与分支保留作历史证据，不并入、不清理（沿 A-03 旧 worktree「保留不动」先例）。
3. 新行归档时在积压表备注回链本裁决，孤儿分支随后可由控制会话统一清理。

## 6. 版本与契约影响预估（方向性）

| 行 | 方向性影响 |
|---|---|
| 难度系统 | 世界 metadata 升版（难度字段）+ 配置项追加；无 wire 结构变更 |
| 护甲 | 玩家 schema 升版（护甲槽位）+ 协议升版（护甲值同步）+ HUD 护甲条 |
| 远程敌怪与投射物 | 协议升版（投射物消息族）；敌怪持久化 schema 可能升版或新 schema |
| 完整分堆与快捷搬运 | 协议升版（容器命令扩展） |
| 斧铲 / 采掘连带收获 / 骨粉来源 / 熟食 | 物品、配方与掉落表追加；大概率无 wire |
| 基础洞穴生成 | worldgen 变更 + engine ABI 可能升版（carve 单一真源入 Rust，沿树苗行先例）+ worldgen golden |
| 装饰材料 / 作物来源 | worldgen 材料表与生成规则 + golden；engine ABI 可能升版 |

绝对版本号一律以各行实现时的 main 为准（版本号互斥规则不变）。

## 7. 完成的定义（验收口径）

1. `acceptedUnobtainableItems` 为空切片，价值闭包守卫正反两向全绿。
2. 工具/武器/防具矩阵齐全：镐锄（石铁）、剑（木石铁）、斧铲（木石铁）、护甲、弓箭并存且各有权威闭环。
3. 难度分支可用：和平/普通/困难行为可由存档与配置区分。
4. 基础洞穴可达，煤/铁可在地下采掘；旧区块不被改写。
5. 空背包起家 e2e 从「石镐」延伸到「铁器时代」（熔炉→铁锭→铁工具或护甲），全程无测试后门。
6. 既有四条关键能力路径（工作台、照明、采掘工具、食物）与熔炉/熔炼链正向断言持续绿。

战役收官时在 `docs/notes/progress.md` 记录闭环达成，并回改积压表将本设计标记为已兑现；此后再开新方向的规划讨论。

## 8. 风险与在案裁决点

- **远程敌怪与共享边界**：它是夜行者之后第一类行为显著不同的敌怪，「第二类敌怪 AI/ECS 共享边界」的评估必须随本行一并执行，不得顺延。
- **worldgen 三行共享不变量**：洞穴、装饰材料、作物来源都改新生成区块的字节流，受「旧区块不改写」与 worldgen golden 约束；三行落地顺序内的每一行都要重订 golden 与改写论证，装饰材料行明确与洞穴行一并裁决。
- **敌怪生成语义**：现行时间门控维持不变；洞穴落地后若要按黑暗生成，属光照禁令重裁，另行立项，不在本战役。
- **骨头来源**：远程敌怪行若交付骷髅类敌怪，骨头来源裁决应与其掉落表协调，避免骨粉行重复裁决。
- **木档镐锄缺档**：现行起家链路为原木→木板→工作台→石镐，跳过木档镐锄，属已接受现状；本战役不补，除非控制会话另行裁决。
- **B-42 合入时序**：潜行 PR 合入后协议进入新版本，阶段一全部版本预估基于届时 main。
