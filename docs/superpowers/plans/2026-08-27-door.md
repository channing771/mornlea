# B-17 门 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付单材质双格高木门（8 下+1 上共 9 BlockID，下8按方向×开/关，铰链固定左），权威原子放置/开合/破坏，关闭实心开启可通行。

**Architecture:** 沿用“每态一 ID”范式在 `BlockIDMax 62→71` 追加 `IsDoor` 区间，`DoorUpper` 单 ID 由 `lower` 推导方向；`sim/door.go` 承载放置/交互原子逻辑，`mining.go` 接入双清掉落，`mesh/quad` 薄板几何按方向旋转，无 `protocol/schema` 升版。

**Tech Stack:** Go 1.26, `internal/core` registry, `internal/assets` material, `internal/mesh` + `engine/crates/mornlea_engine`, `internal/sim` deterministic tick, `internal/storage` chunk v9

**Spec:** `docs/superpowers/specs/2026-08-27-door-design.md`

## Global Constraints

- `BlockIDMax 71` (`CarrotStage7 61 → DoorLower 62..69 → DoorUpper 70`)，`ItemIDMax 44` (`ItemDoor 43`)，哨兵前 append-only，`RegisteredBlock = id < BlockIDMax`
- `ProtocolVersion 27`、`Chunk schema v9`、`engine ABI v7`、`client ABI v9`、`benchmark scenario v19` 均不变
- 双格原子：放置/开合/破坏均同时改 `lower+upper`，跨区块 `upper` 未就绪则拒绝
- 碰撞：关厚 3/16 贴边，开启旋转 90° 薄边；射线关实心开可穿透；`fluid` 关不可流入开可流入
- 配方：`3×3 木板6（两列满）→ Door×3` 接 `Workbench` 后
