# 当前限制

本文承接 README「当前限制」一节，按 2026-08-28 基线逐条对照代码、测试与 `openspec/specs/` 核实：每条只陈述当前确实成立或确实不存在的边界，可验证、不记录历史沿革。

## 平台与网络

- 可运行图形客户端目前仅支持 macOS，主要在 Apple Silicon 上验证；Linux 只提供 `make build-linux-server` 产出的无图形专用服务端；
- TCP 多人联机仅面向可信局域网，协议没有认证或加密，服务端不能暴露到公网；
- 尚无服务器发现、游戏内连接菜单或断线自动重连；远程连接只能以 `--connect` 命令行参数发起，一台服务端最多容纳 8 名玩家（`--max-players` 只接受 `1..8`）；
- 图形客户端默认在完整程序化注册表上应用内嵌的 Pixel Perfection 子集，未映射 layer 回退到程序化材质；仓库不包含官方 Minecraft 美术资源。

## 世界与光照

- 世界时间由服务端权威推进，一个昼夜固定为 `24000` tick，所有客户端从权威玩家状态观察同一相位；地形、远端玩家、掉落物和天空背景按固定曲线随昼夜变化，HUD 与昵称不受世界明暗影响；
- 天空光和静态方块光都由客户端从权威方块镜像派生：天空光直射起点为 `15`，穿过流体每格额外衰减 `1`、穿过植物不额外衰减；方块光只有发光块发出、以 `15` 起步且只经空气传播，水与玻璃同样阻断，未知邻区按阻挡和黑暗处理；光照不写入存档、不进入网络 payload；尚无真实火把、彩色或动态光、动态阴影与天气；
- 水默认由 worldgen 注入，并以水源加七个流动等级、斜水面、半透明 water pass、水中物理、氧气与溺水形成权威闭环；水不进物品表，尚无水桶或玩家放置流体；
- 方块注册表固定：煤矿、铁矿、沙子、砾石、黏土、雪块与橡树按种子只在新生成区块确定性出现；圆石、平滑石、玻璃、砖块、白色羊毛、红色瓦块、苔藓圆石等其余材料不自然生成，已保存区块不会被批量改写；材料尚无重力、腐烂或融化行为；
- 木门与工作台是熔炉、箱子之外仅有的两个交互方块：木门双格放置、右键开合，工作台把合成网格有效尺寸提到 3×3；两者均可放置、采掘并掉回本体；
- 农业闭环覆盖小麦、马铃薯、胡萝卜三种八阶段作物：锄头翻地、耕地干湿双向转化、固定预算生长、骨粉催熟、收获随机掉落、落地踩踏回泥土、洪水冲毁作物；收获与冲毁的具体掉落数量由 `(worldSeed, tick, 维度, 坐标)` 的确定性哈希给出，同输入重放逐件一致；
- 存档缺失的新玩家在背包前 14 格各获得 64 个固定材料，并在第 15 格获得 64 颗小麦种子；这是新玩家取得第一颗种子的唯一途径，已有玩家不会补发。

## 物品、容器与合成

- 快捷栏固定 9 格；可用工具与对应损坏物品每格最多 1 个，其他当前物品每格最多 64 个；快捷栏装满时仍可挖掘，物品留在地面；
- 掉落物属于所属区块：每区块最多 32 堆；可堆叠物品在同位置最多合并到 64，工具与损坏形态每格上限为 1、不会合并；区块掉落物已满时可采集方块的采掘会被拒绝且方块保持不变；
- 采掘与方块破坏掉落的拾取延迟编译默认值为 `10` 个 active tick，主动丢弃与死亡掉落则默认为 `40` 个 active tick；延迟结束后，默认拾取半径 `1.25` 格内的玩家可以拾取。掉落物的编译默认寿命为 `6000` 个 active tick，且只有玩家兴趣范围（区块半径 2）内的掉落物才会推进寿命与拾取；
- 拾取按整堆进行：先填快捷栏再填背包（同类未满格优先，其次最低空格），两者都满时剩余物品留在地面；拾取结果若挤占合成网格回收所需的背包预算，整堆拒绝；
- 背包、容器与合成网格都只支持两次点击整堆移动：空目标接收整堆、同物品按堆上限合并并保留余量、不同物品交换；尚无拆分堆、拖拽与快捷搬运；
- 合成是服务端权威的瞬态合成网格：个人网格 2×2，对工作台完成权威交互后为 3×3；网格与产物格不入任何存档，服务端重启后同一玩家的网格为空且尺寸回到 2，关闭、断线与死亡由「网格可无损装回背包」的回收不变量兜底；打开工作台同样结束既有容器查看关系；
- 服务端固定形状配方共 14 条，接受水平镜像摆放（镐与锄等工具配方除外）；图形背包呈现合成网格与权威派生的产物格；尚无批量合成、合成队列或配方书；
- 熔炉固定三条熔炼映射（粗铁→铁锭、沙子→玻璃、黏土块→砖块）且只接受煤炭燃料，每区块最多 32 个；尚无多燃料、经验、自动化或离线进度补算；
- 工具尚无修复或损坏物品回收；采掘进度按玩家独立，尚无多人共享进度与裂纹贴图；
- 每区块最多 16 个箱子，每个箱子固定 27 格且接受任何已注册物品；每名玩家同时只能查看一个容器，打开箱子会结束熔炉查看关系，反之亦然；尚无大箱子合并、箱子命名、排序、漏斗、比较器、潜行放置或任何自动化；
- 主动丢弃只支持单件原地转移：服务端在同一权威 tick 内校验玩家、选中栏位、脚底区块与每区块 32 个掉落物槽后原子扣除一件并在脚下创建掉落物，默认 `40` 个活动 tick 内不可拾取；合并到同位置旧堆时保留其 ID 与寿命时间线，只把拾取禁止窗口延长到较长的来源延迟；
- 尚无整组丢弃、丢弃数量选择、投掷速度、掉落物重力与水平移动、所有者专属拾取与客户端预测；
- 骨粉可把视线内的未成熟作物推进一阶段并恰好消耗一个，但当前没有配方或自然来源，正常游玩中无法取得。

## 生存与状态

- 生命值、氧气、饥饿/饱和/疲劳、进食、自然回血门控、饥饿伤害、溺水、摔落与玩家近战/PvP 均由服务端权威结算；生存 HUD 只显示已确认值：采掘进度只呈现服务端确认结果，进食进度条是其中唯一的客户端预测元素；
- 食物共四种：面包、马铃薯、胡萝卜与毒土豆；连续使用默认 `32` tick 原子结算一件，毒土豆当前只按普通食物结算，中毒效果尚未实现；
- 疾跑由 `Left Ctrl` 或 `Left Shift` 触发，仅在地面、前移、非浸没且饥饿值至少为 `6` 时按默认 `1.3×` 加速，并与起跳、游泳、近战命中一样按固定表收取疲劳；
- 当前仍无潜行、怪物，以及窒息、岩浆、火焰等伤害源；也没有床、自定义重生点或专门的死亡界面；死亡在同一权威 tick 内结算：36 个物品栏格逐格掉进世界、玩家传回出生锚点满血重生，外部观察不到生命值为 0 的中间状态。

## 伙伴

- 伙伴由服务端权威执行，最多四个；普通方块之外，箱子与熔炉也是合法采掘目标——本体加全部内容物按批量结算、全或无入包，任一堆放不下则整体不结算且任务以稳定原因失败；
- 空闲台词只面向仍在线且水平距离不超过 `16` 格的最近真实发令者；
- 伙伴明确不执行种植或收获：农业方块被 Planner 契约与权威模拟双重拒绝。

## 性能与验证边界

- 视觉验证需要 GPU，尚未接入 `go test ./...` 或 CI，只作为本地 make target 与人工评审步骤存在；
- benchmark 与 `perfcheck` 的性能数值只记录，不改变退出状态；报告完整性、真实 overflow、数据丢失和 I/O 错误仍然硬失败。
